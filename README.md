# 문형수 · amecoder

저는 백엔드 개발자이자 AI 엔지니어인 문형수입니다. 프론트엔드를 포함한 풀스택 개발도 합니다.
사람들이 실제 업무에서 사용하는 서비스를 만들고 운영하는 데 관심이 있습니다.
“함께 일하고 싶은 사람이 되자!”가 제 좌우명입니다.

그동안 커머스와 교육, 웹툰, 채용, 방송, 보험 분야에서 서비스를 개발해 왔습니다.
결제와 정산, 데이터 변경을 전달하는 이벤트 처리처럼 서비스의 기본이 되는 기능을 구현하고 운영했습니다.

개발할 때는 실제 업무가 어떻게 이루어지는지부터 살펴봅니다.
필요한 기능을 정하고, 운영하면서 사용자의 반응을 확인해 고칠 부분을 찾아갑니다.

최근에는 AI를 업무 시스템에 연결하는 일을 하고 있습니다.
팀으로 만든 AI 세일즈 콜 플랫폼에서는 실시간 음성 연동과 LLM 운영을 맡았습니다.

개발 과정에서도 AI와 함께 일합니다.
Claude에 초안과 분석을 맡기고, 생성된 코드는 제가 검토한 뒤 반영합니다.

개인적으로는 세무 일을 하는 가족의 업무를 계기로 [세무 Tools](https://semu.ai.kr)를 만들었습니다.
세무·회계 업무에 쓰는 계산·변환 도구와 세무 가이드를 참고해 답하는 챗봇을 만들고 운영하고 있습니다.
2026년 1월에 서비스를 시작했고, 지금까지 약 7,400명이 이용했습니다.

[hello-llm](https://github.com/amecoder/hello-llm)에는 개발 지식이 없어도 LLM을 잘 활용할 수 있도록 사용 방법을 정리했습니다.
용어를 풀어 쓰고 바로 입력해 볼 예시를 담아 [웹 가이드](https://amecoder.github.io/hello-llm/)로도 공개했습니다.

경매 방식으로 중고 물건을 거래하는 [drrrk(드르륵)](https://github.com/amecoder/drrrk)의 백엔드도 만들었습니다.
지금은 중단한 프로젝트지만 간단한 커머스를 만드는 데 참고할 수 있도록 코드를 공개해 두었습니다.

개발에는 Kotlin·Java와 Spring Boot, Python과 FastAPI를 사용하고, AWS에서 서비스를 운영합니다.
